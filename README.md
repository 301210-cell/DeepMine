# DEEPMINE — Underground Mining Simulator

A 2D pixel-art mining adventure made with **Godot 4.7** (GDScript). Start with a worn pickaxe and a half-abandoned camp, dig through six underground biomes, find rare minerals, geodes, fossils and ancient artifacts, build machines, and grow your miner through a branching honeycomb skill tree.

## Play it

* **Windows build:** download `DeepMine-Windows.zip` from the repository's **Releases** page, unzip it, and run `DeepMine.exe`. No install needed.
* **From source:** install Godot 4.7 (or newer 4.x), open Godot, click **Import**, choose this folder's `project.godot`, then press **F5**.

## Controls

| Action | Input |
|---|---|
| Move | A / D or Left / Right arrows |
| Run | Hold Shift |
| Jump | Space |
| Climb ladders | W / S or Up / Down arrows |
| Mine | Hold Left Mouse (aim at a block) |
| Use the selected hotbar item (place ladder or torch, throw dynamite, drink a tonic) | Right Mouse |
| Select a hotbar slot | 1–6 or the mouse wheel |
| Interact (talk, open machines or shops, ride elevators and carts, open chests) | E |
| Inventory | I or Tab |
| Skill Tree | K (unlocked during the tutorial) |
| Map | M |
| Journal (quests, collection, discoveries, achievements) | J |
| Quick-drink a Health Tonic | H |
| Fullscreen | F11 |
| Pause / close a window | Escape |

Every key except the mouse buttons can be rebound in **Settings → Controls**.

## Features

* **Physical mining:** blocks crack in stages with impact sparks, debris and sound. Tool tier gates the tougher rock, and the game tells you which pickaxe you need.
* **Six biomes:** Stone Caverns, Iron Depths, Crystal Caves, Frozen Depths (slippery ice), Magma Caverns (lava and heat), and the Ancient Core. Each is about 300–700 m deep, sealed by a barrier that needs a stronger tool.
* **Over 70 items:** 48 collectible minerals, gems, specials, geodes, fossils and artifacts, plus bars, polished gems, essences and consumables. Rarities run from Common to Legendary.
* **Skill tree:** 40 nodes in 4 branches (Mining Mastery, Exploration, Equipment, Engineering), with up to 5 ranks each and prerequisites. Unlocks animate energy along the paths, and a reset refunds 90%. Every skill changes real gameplay through one central stat system.
* **Equipment:**
  * 7 pickaxes (Basic → Plasma Mining Tool) and portable drills
  * backpacks, lanterns, scanners, and boots including grip, thermal and gravity
* **9 camp machines:** Smelter, Crusher, Gem Polisher, Automated Drill, Ore Sorter, Advanced Smelter, Crystal Extractor, Mining Robot, Deep-Core Drill. Each animates while working and can be upgraded.
* **Getting around:** an elevator with 13 checkpoints, rideable mine carts, ladders, torches and dynamite.
* **Secrets:** hidden caches behind cracked walls, abandoned loot carts, and 7 special chambers, including the Heart of the Mountain at 3,150 m.
* **Mara's tutorial:** 12 short steps, skippable and replayable. After it come 15 main quests, rotating optional challenges and 29 achievements.
* **8 timed events:** Crystal Surge, Geode Fever, Ore Rush, Meteor Shower, Abandoned Cart, Double Extraction, Ancient Discovery and Rare Expedition.
* **Day and night:** a 24-minute day with sunrise, dusk, stars and camp lamps. Caves get darker the deeper you go.
* **Music and sound:** 8 music tracks, 6 ambience loops and 50 sound effects.
* **Saving:** autosave plus a manual Save, with a backup file, version migration and corruption recovery. Progress is never erased silently.

## Project structure

```
scenes/      main (Boot, MainMenu, LoadingScreen, Game), player, ui (HUD, UIRoot, SkillTree, panels)
scripts/     autoload (Events, ResourceDatabase, GameState, SkillManager, AudioManager, SaveManager),
             world (generator, chunk renderer, camp, entities, background), player, mining,
             machines, progression (quests, tutorial, events, achievements), skills, ui
data/        JSON definitions: resources, blocks, biomes, equipment, skills, machines, loot, quests, events
assets/      sprites, tilesets, backgrounds, ui, fonts, audio (all generated by tools/assetgen)
tools/       assetgen (standalone Godot project that generates every PNG/WAV/FNT), import/capture helpers
tests/       headless smoke tests, automated playtest, screenshot tool
```

`ARCHITECTURE.md` documents the asset contract and system APIs. `DEVELOPMENT.md` holds the development checklist.

## Art & audio

All artwork, fonts, music and sound effects are original. They are generated procedurally by the scripts in `tools/assetgen/`, so there are no third-party assets. To regenerate one set:

```
Godot_console.exe --headless --path tools/assetgen --script res://gen_tiles.gd
```

## Exporting

The project includes a **Windows Desktop** export preset (Project → Export). It produces a single self-contained `DeepMine.exe`. You need Godot's export templates for 4.7 installed (Editor → Manage Export Templates).
